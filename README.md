# ServiceNow CSA クイズ学習アプリ

ServiceNow CSA（Certified System Administrator）試験対策のためのクイズ学習用Webアプリです。
ILT（集合研修）で共有された「eBookハイライト箇所（抑えるべき内容）」をもとに作成した4択・シナリオ問題を、ランダム出題形式で学習できます。

## 使い方

スマートフォンやPCのブラウザで以下のURLにアクセスするだけで利用できます（インストール不要）。

```
https://arakawa-yuya.github.io/csa_quiz_app/
```

## 主な機能

- 出題モードを選択可能：全問題からランダム／間違えた問題の復習／お気に入りのみ
- 出題数を選択可能：5問・10問・20問・全問
- 1問ずつ出題し、回答すると即座に採点・解説を表示
- 解説はPDFの「解説」列の内容を使用し、関連する表の行番号（表No.）も表示
- 選択肢は数字キー（1〜4）でも回答可能（回答の簡素化）
- 間違えた問題は自動的に「復習リスト」に登録され、後から絞り込んで再挑戦できる
- 各問題に☆マークでお気に入り登録が可能で、お気に入りのみを出題するモードも用意
- 進捗・正誤情報はブラウザのlocalStorageに保存されるため、次回アクセス時も引き継がれる
- スマートフォン表示に最適化（ダークモード対応）

## ファイル構成

- `index.html` — アプリのHTML構造
- `style.css` — スタイル（レスポンシブ・ダークモード対応）
- `data.js` — クイズ問題データ（PDFの表内容をもとに作成）
- `app.js` — クイズのロジック（出題・採点・復習・お気に入り管理）
